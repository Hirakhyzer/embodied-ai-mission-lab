# Roadmap

## v0.2 — Mission authoring

- Editable maps, obstacles, targets, and robot starting poses
- Mission import as well as export
- Multi-step goals and task graphs
- Replay timeline

## v0.3 — Intelligence plugins

- Planner plugin interface
- LLM-generated mission decomposition
- Learned policy sandbox
- Evaluation metrics and benchmark scenarios

## v0.4 — Multi-robot laboratory

- Fleet state and robot assignment
- Shared map and conflict prevention
- Cooperative transport and search scenarios

## v0.5 — External simulation bridges

- Webots adapter
- MuJoCo adapter
- ROS 2 bridge specification
- Recorded sensor stream playback

## v1.0 — Embodied AI experimentation platform

- Stable mission and capability schemas
- Experiment registry and reports
- Safety policy packs
- Reproducible benchmark suite
- Hardware adapter SDK
